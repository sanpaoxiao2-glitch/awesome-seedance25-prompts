# FPV 穿越飞行

**模式**：文生视频 | **时长**：25s | **画幅**：16:9

第一人称高速穿越，一镜到底。这条的难点全在路径控制——必须把空间关系写成有序的路线，否则模型会飞着飞着掉头。

## 需要的素材

无。有航线示意图的话传 1 张，注意提示词里要写明「不要出现红线」。

## 提示词

```text
第一人称 FPV 竞速无人机视角，电影级实拍质感，一镜到底无剪辑，总时长 25 秒。
晴天，通透蓝天，真实光照与大气透视。
镜头始终朝向无人机前进方向，高速飞行伴随轻微的机身姿态倾斜与惯性摆动。

空间关系严格按以下顺序单向推进，全程向前，不回头、不倒飞、不绕回起点：
起点（峡谷左下方绿色山坡）→ 瀑布顶 → 瀑布底 → 山谷村落 → 双峰之间的缝隙 → 山谷深处远景

运动路径，按顺序连续衔接：
无人机从峡谷左下方的绿色山坡低空启动，贴着坡面加速爬升，
朝左侧崖壁上倾泻而下的大瀑布飞去；
沿瀑布左侧崖壁一路向上攀升，绕到瀑布顶端，从上方俯瞰跌水口与源头溪流。

越过瀑布顶后压低机头，沿瀑布外侧崖壁向下俯冲，
掠过飞溅的水雾边缘但不进入水帘，落到瀑布底部的河面上方；
随即转向右侧，沿蜿蜒的河流以流畅的波浪线高速前飞，
贴着屋顶掠过山谷中段的石屋村落。

穿过村庄后继续沿河谷向右深入，全速冲向远景中最高的两座山，
从两座峰之间的 V 形缝隙正中央穿过，
出画进入开阔的山谷远景，速度逐渐稳定收尾。

画面呈现真实的航拍质感，阳光从右上方照射，
崖壁的岩石纹理、瀑布水雾的体积光、村落屋顶的材质和河水的反光都要真实。
远景有自然的大气透视，越远越淡。

声音：<持续的螺旋桨高频嗡鸣> <穿越瀑布区域时的水声由远及近再远去>
<高速飞行的风噪> 无背景音乐。

负向限制：不出现任何画面文字、标记、红线或编号；
不要从正面穿过水帘，不要钻进水雾里；
不要朝后飞，不要无故盘旋停滞；
天气和光照全程保持一致；
总时长严格 25 秒，中途不得黑场或加速跳切。
```

## 效果说明

两个写法决定成败：

1. **先给路线摘要，再给详细描述**。开头那行「起点 → 瀑布顶 → 瀑布底 → 村落 → 缝隙 → 远景」是给模型的空间骨架，后面的详细段落是填充。只写详细描述而不给骨架，模型容易在中段迷路。

2. **负向限制必须明确「不回头、不倒飞、不盘旋」**。FPV 场景里模型最常见的失败是飞着飞着绕回去了，这三条直接堵死。

## 改法

- **换城市**：
  ```
  从东方明珠塔底座附近的低空起点出发，先极速拉升并环绕塔身、下球体、
  上球体与塔尖，再高速飞越黄浦江冲向陆家嘴，
  在上海中心、环球金融中心、金茂大厦之间左右穿梭、上下起伏，
  最后沿浦东天际线向右前方冲刺，在开阔的城市远景中结束。
  ```
- **改时长**：15 秒版本删掉「瀑布顶 → 瀑布底」这一段，路线缩短为四个节点
- **换时间**：把「晴天，通透蓝天」改成「黄昏金色余晖」或「雨后，云层低垂，空气中有水汽」
- **加室内穿越**：在路径中插入 `穿过村落中一间敞开门窗的石屋，从前门进后窗出`
