# 拟人化 IP 角色

**模式**：文生视频 | **时长**：20s | **画幅**：16:9

把非人角色放进真实场景演戏，形象、动作和口音全程统一。IP 短片和品牌吉祥物内容的通用做法。

## 需要的素材

无。有角色设定图的话传 1–3 张多视角图。

## 提示词

```text
美国西部片风格，超真实电影感写实质感，不要卡通化。
烈日下的黄沙小镇酒馆内部，木质结构，光线从百叶窗缝隙斜射进来，
空气中有可见的浮尘。

0-3s    一只戴迷你牛仔帽、穿棕色流苏皮马甲的橘猫推门而入，
        门轴发出<吱呀一声>，带起一小片尘土。
        镜头在门口，中景略仰拍，橘猫的剪影逆着门外的强光。

3-7s    镜头快速推向吧台。站在吧台后擦杯子的络腮胡老板看到橘猫，
        手一抖，玻璃杯脱手<碎落在地>。
        随即切到角落，三位牛仔同时转头，嚼烟草的嘴定格。
        特写他们瞪大的眼珠和抽动的胡茬，
        每次切换配一声<鞭梢抽风的呼啸>，共三声。

7-12s   镜头回到橘猫中景。它用后爪蹬了蹬木地板上的灰尘，抬起下巴，
        用奶凶但拖长调子的语气说：
        台词语言：美式英语，带西部拖腔。橘猫说：
        {Milk. Fresh. Ain't nobody gonna greet me?}

12-16s  全场静默半秒。随即牛仔们齐刷刷摘下帽子，
        发出拉长的<哇噢——>惊叹声，<口琴滑音向上扬起>。

16-20s  镜头 360 度环绕橘猫拍摄，跟随它走向吧台、
        跳上高脚凳的过程，最后停在它端坐凳上的傲娇表情特写，定格。

画面呈现真实的西部片质感：木材的干裂纹理、皮革的磨损、
猫毛在逆光下的边缘轮廓光、浮尘在光柱中的漂浮都要真实。
严格遵循真实物理：有重量、有摩擦、有接触阴影，不漂浮。

声音：无背景音乐，只保留现场音效和口琴。
环境有低音量的木质吱呀声和远处的风声。

不要 CGI 光泽感，不要迪士尼式的大眼睛卡通化，
不要字幕，不要慢动作。
```

## 效果说明

拟人化角色最容易翻车的是滑向廉价卡通。**解法是把质感锚定在真实世界**：「超真实电影感写实质感」放在开头，「不要迪士尼式大眼睛卡通化」放在结尾，中间用真实材质词（木材干裂、皮革磨损、毛发轮廓光）夹住。

「奶凶但拖长调子」这种矛盾修辞 2.5 能理解，比单写「可爱」有效。台词前标明语言和口音是必须的，见 [声音与多语言](../../docs/05-audio-and-dialogue.md#进阶控制口音和地区变体)。

## 改法

- **换角色**：任何动物或物体都可以，保留「入场 → 全场反应 → 开口 → 反转 → 收尾」这套节拍
- **换类型片**：黑帮片、武侠片、太空歌剧都适用，改开头的风格声明和场景
- **拟物角色**：植物、家具、食物也可以拟人化，例如：
  ```
  中景画面中，拟人化的向日葵组成一支乐队，植株整齐排布。
  队伍前方的向日葵用右侧叶片下压立式麦克风调整高度，
  用低沉柔和的英式口音说：{伙伴们，让我们用歌声传递美好。}
  其余向日葵各持不同乐器：有的用叶片敲圆鼓，有的背着吉他，有的吹奏管乐。
  温暖阳光倾泻，金黄花瓣在光影下明艳，<微风掠过花丛的沙沙声>。
  ```
- **锁定形象**：加 `@图片1 @图片2 共同定义同一只橘猫的正面和侧面外观，成片中始终只有这一只猫`
