# 一键换画风

**模式**：视频编辑 | **时长**：对齐原片 | **画幅**：对齐原片

构图和运镜完全不变，整体视觉风格切换。一条素材出多个风格版本，适合做 A/B 测试或者风格提案。

![多风格依次替换](../../assets/clips/style-swap.webp)

## 需要的素材

- `@视频1` — 原片

## 提示词

单风格版本：

```text
保持 @视频1 的构图、运镜轨迹、动作节奏和时长完全不变，
将画面风格改写为水墨动画：
墨色浓淡分层，笔触边缘有晕染，大面积留白，
人物和景物保留水墨的书写感而非照片写实。
不改变人物位置、动作和镜头运动。
```

多风格依次切换（一条片子里换四种）：

```text
保持 @视频1 的运镜和节奏不变，将画面风格按时间依次改为：
0-25%   黑白漫画风格，高对比，网点阴影，粗描边
25-50%  日式动画赛璐璐风格，平涂色块，锐利高光
50-75%  美式硬核插画风格，厚重线条，饱和度高，强阴影
75-100% 水墨动画风格，墨色晕染，留白，笔触感

风格切换在指定的时间点干脆完成，不做渐变过渡。
人物位置、动作、镜头运动和时长全程不变。
```

## 效果说明

单风格版本用于成片交付。多风格版本适合做风格提案——客户一次看四种，省掉来回四轮沟通。

## 可用的风格词

| 风格 | 描述关键词 |
|---|---|
| 黑白漫画 | `高对比，网点阴影，粗描边，速度线` |
| 日式动画 | `赛璐璐，平涂色块，锐利高光，轻描边` |
| 美式硬核 | `厚重线条，高饱和度，强阴影，粗犷笔触` |
| 水墨 | `墨色浓淡分层，笔触晕染，大面积留白` |
| 岩彩壁画 | `矿物颜料质感，赭石石青石绿朱砂，平面分层` |
| 定格动画 | `黏土材质，手工感，移轴景深，轻微抖动` |
| 老电影 | `黑白，颗粒，划痕，轻微闪烁，4:3 遮幅感` |
| 胶片 | `35mm 颗粒，暗角，色彩偏暖，轻微光晕` |
| 铅笔素描 | `石墨质感，交叉排线，纸张纹理` |

## 改法

- **只改色调不改风格**：`保持 @视频1 不变，将整体色调从冷蓝改为暖橙，光线方向不变`
- **只改光线**：见下方
- **加风格参考图**：`风格参考 @图片1 的色彩、笔触和质感，构图与运镜保持 @视频1 不变`

## 顺带一提：光源重布

同样是编辑能力，改光比改风格更常用：

```text
将 @视频1 的光线从正午刺眼的顶光改为日落时的低角度侧光，
色温转暖，阴影方向对应改变并拉长，明暗层次重新分布。
构图、人物、动作和运镜保持不变。
```
