# 改年龄与表情

**模式**：视频编辑 | **时长**：对齐原片 | **画幅**：对齐原片

画面、镜头、节奏全部不动，只改演员的年龄和微表情。一镜连续完成，五官随年龄渐变而不漂移。

## 需要的素材

- `@视频1` — 原片，人物面部清晰可见

## 提示词

```text
保留 @视频1 的构图、机位、光线方向和表演节奏，
只改写画面中女主角的样貌与神情：

让她从二十多岁自然地老去到六十岁，皮肤纹理、发色和眼周结构随年龄渐变，
五官比例保持同一个人，不漂移、不换脸。
同时神情从隐忍慢慢化开：泪光在眼眶里聚起，滑过眼角，
嘴角一点点扬起，最后破涕为笑。

全程一镜到底，不跳切、不闪烁，年龄和情绪的变化连续平滑。
背景、服装、镜头运动、色调和时长全部保持不变。

不要慢动作，不要变速，不要重新构图。
```

## 效果说明

同时做两件事：年龄渐变和情绪递进。2.5 对「隐忍 → 泪光 → 破涕为笑」这类多层情绪的理解比上一代明显更好，可以直接用自然语言描述，不需要拆成具体的面部动作。

**关键写法**是「五官比例保持同一个人，不漂移、不换脸」——不写这句，老化过程中容易变成另一个人。

## 改法

- **只改年龄不改表情**：删掉「同时神情从隐忍…」整段
- **反向变年轻**：改成「从六十岁自然地年轻到二十多岁」
- **只改表情**：删掉年龄部分，保留情绪递进的描述
- **换性别 / 人种**：这属于换人，不属于年龄编辑，用参考图编辑更稳：
  ```
  将 @视频1 中的女主角替换为 @图片1 的形象，
  动作、表情节奏、镜头和背景保持不变。
  ```

## 注意

编辑输出的**画幅严格对齐原片，时长基本对齐原片**，在提示词里指定比例或时长不生效。详见 [视频编辑与延长](../../docs/04-video-editing.md#编辑会强制锁定的参数)。
