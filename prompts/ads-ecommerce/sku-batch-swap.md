# SKU 批量换款

**模式**：参考生成 + 视频编辑 | **时长**：对齐原片 | **画幅**：对齐原片

拍一条，出一整条产品线。同一个镜头里批量替换商品的款式和颜色，运镜、光线、节奏完全一致，只有产品变。

| 主体替换 | 爆款运镜复用 |
|---|---|
| ![主体替换](../../assets/clips/subject-swap.webp) | ![耳机广告](../../assets/clips/headphone-ad.webp) |

## 需要的素材

- `@图片1` — 主款产品图
- `@图片2` — 场景图
- `@图片3` 起 — 其余 SKU 的产品图，一款一张

## 第一步：生成母版

```text
@图片1 用于饮料瓶的瓶身造型、标签设计和材质，不采用图片背景。
@图片2 用于场景的台面材质、背景元素和光线方向，不采用图中商品。

一支饮料瓶在 @图片2 的场景中展示，镜头按以下顺序连续切换，衔接流畅：
0-4s    特写，瓶口和瓶盖细节，水珠沿瓶身滑落
4-9s    近景，标签正面完整可见，瓶身缓慢自转 90 度
9-15s   中景，瓶子与场景的关系，背景轻微虚化
15-20s  远景，完整场景，瓶子居中，镜头缓慢后拉定格

主体在全程保持一致，瓶身比例、标签位置和材质不发生变化。
画面呈现干净的商业产品广告布光，柔和均匀，背景有轻微渐变。
水珠、玻璃通透感和标签的印刷质感要真实。

声音：无对白，无背景音乐，只保留极轻的环境底噪。
不要字幕，不要产品参数文字。
```

## 第二步：批量换款

拿上一步的成片当原片，每个 SKU 跑一次：

```text
将 @视频1 中的饮料瓶替换为 @图片3 的粉色款，
瓶身在画面中的位置、比例、旋转角度和水珠分布保持一致，
镜头运动、光线、背景和时长完全不变。
```

```text
将 @视频1 中的饮料瓶替换为 @图片4 的紫色款，其余保持不变。
```

```text
将 @视频1 中的饮料瓶替换为 @图片5 的绿色款，其余保持不变。
```

## 效果说明

一次生成 + N 次编辑，比 N 次完整生成便宜且一致性更好。同一系列的产品视频放在一起时，运镜完全一致会显得很专业——手工重拍做不到这种一致。

第一条替换写得详细一点（位置、比例、角度、水珠），后面几条可以简写，模型会沿用同样的处理方式。

## 改法

- **换品类**：饮料换成化妆品、3C、鞋服都可以，把「饮料瓶」和材质描述替换即可
- **只换颜色不换款**：`将 @视频1 中饮料瓶的瓶身颜色改为哑光黑，标签设计、造型和材质保持不变`
- **换模特**：`将 @视频1 中的模特替换为 @图片3 的形象，动作、服装、镜头和背景保持不变`
- **改价签 / 文案**：`将 @视频1 中画面右下角的价格数字改为 ¥129，字体、位置和大小保持不变`

## 注意

编辑输出的**画幅和时长对齐原片**，不接受自定义。所以第一步的母版一定要按最终交付规格生成——画幅错了就得重做母版。详见 [视频编辑与延长](../../docs/04-video-editing.md#编辑会强制锁定的参数)。
