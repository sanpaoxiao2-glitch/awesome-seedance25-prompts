# 提示词公式

## 基础公式

```
主体 + 动作或事件 + 场景与环境 + 视觉风格 + 运镜或切镜 + 声音
```

前两项必写，后四项可省。**但每省一项，模型就自由发挥一项**——省掉运镜，它会自己决定推还是拉；省掉声音，它可能给你配一段莫名其妙的钢琴曲。

各项该写什么：

| 要素 | 写什么 | 注意 |
|---|---|---|
| **主体** | 谁 / 什么，外观特征 | 有参考图就别写外观，见 [03](./03-reference-materials.md) |
| **动作或事件** | 在做什么，怎么发展 | 先概括主要过程，只给关键动作补细节 |
| **场景与环境** | 地点、时间、天气、空间关系 | 空间关系写清楚，多主体时尤其重要 |
| **视觉风格** | 光线、色彩、材质、质感、氛围 | 见 [06 光线词表](./06-camera-and-lighting.md) |
| **运镜或切镜** | 景别、机位、镜头运动、对焦、衔接 | 见 [06 运镜词表](./06-camera-and-lighting.md) |
| **声音** | 对白、音色、环境声、音效、音乐 | 见 [05 声音与多语言](./05-audio-and-dialogue.md) |

**关于动作**：不要反复描述同一个动作。「她走过去，缓缓地走，一步一步走到窗边」——这种重复会让模型困惑，改成「她走到窗边停下」，再单独补一句你真正在意的细节，比如「脚步很轻」。

**生成参数不用写进提示词**。分辨率、时长、比例这些在生成页面或接口里设置，写在提示词里既不生效又占篇幅。

## 套用模板

```
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

一个填完的例子：

```
一位银发老人在深秋的旧书店里整理书架，取下一本硬壳书，翻开扉页停顿了几秒，
神情从随意变得凝重，最后把书抱在怀里没有放回去。
画面呈现暖黄色调，午后斜射光穿过窗棂在书脊上形成条状光斑，木质书架和纸张
质感清晰，整体安静克制。
镜头先以中景交代书店空间和老人位置，缓慢推近到手部和书页，最后停在他的面部特写。
声音只保留翻页声、木地板轻微的吱呀声和窗外远处的车流声，无背景音乐。
```

## 30 秒要按时间轴写

这是 2.5 和 15 秒时代最大的区别。**一个瞬间撑不满 30 秒**，你不给发展，模型就自己编，编出来的通常是原地重复或者莫名其妙的转场。

最省事的是三段式：

```
0-8s    建立：交代主体、环境、基调
8-24s   发展：一个连续动作或一次情绪转折
24-30s  收尾：明确最后一帧停在哪
```

更精细的做法是直接标时间戳，逐段写。适合广告、科普、剧情这类节奏要求高的片子：

```
0-3s    枯黄的草原上空，一只鹰盘旋。镜头静止仰拍，天空占画面三分之二。
3-8s    鹰俯冲而下，镜头跟随下坠，速度感强烈，草浪在风中翻涌。
8-15s   鹰爪抓住一条蛇，蛇身缠绕挣扎。近景，鹰的羽毛和蛇鳞质感清晰。
15-22s  鹰重新升空，蛇在爪下逐渐停止挣扎。镜头拉远，鹰的剪影在夕阳中缩小。
22-30s  鹰回到崖壁上的巢，两只幼鸟探出头。镜头缓慢推近至巢内，定格。
```

**时间戳写法有两个好处**：一是模型执行更准，二是出问题时你能定位到具体是第几段崩的，改起来有的放矢。

## 正向描述优先

**画面内容用正向描述，别用否定句**。「不要出现汽车」这种写法，模型有时候反而会给你画一辆车——注意力被「汽车」这个词吸引了。

想让画面里没有汽车，正确做法是把场景写满：「空旷的沙漠公路，路面上只有风吹起的沙尘」。写满了，就没地方放汽车。

那什么时候用否定？三种情况：

1. **素材职责的排除项**：`@图片1 用于人物外观，不采用图片背景` —— 这是明确的边界声明，必须写
2. **编辑范围的锁定**：`其余画面保持不变` —— 这是编辑能力的核心写法
3. **容易误带入的东西**：`不要字幕`、`不要水印`、`不要慢动作` —— 这些是模型的默认倾向，需要明确关掉

除此之外的画面内容，一律正向写。

## 负向限制清单

放在提示词末尾，专治模型的默认习惯：

```
不要字幕，不要水印，不要文字标记。
不要慢动作，不要变速。
不要人物肢体扭曲，不要重复的脸。
不要 CGI 光泽感，不要游戏引擎质感，不要风格化 3D 外观。
不要舞台表演式的打光，不要过度调色滤镜。
```

按需挑，别全抄——负向词太多会稀释正向描述的权重。一般 3–5 条足够。

## 一条经验：先短后长

30 秒一次生成的成本和等待时间都不低。**先用同一段提示词生成 5–8 秒验证方向**，确认主体、风格、运镜对了，再扩写成完整时间轴跑 30 秒。这个习惯能省掉一半的重跑。
