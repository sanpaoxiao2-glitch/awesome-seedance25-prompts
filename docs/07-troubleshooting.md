# 翻车排查

按症状查，每条给出原因和具体改法。

## 人物类

### 人脸中途变形 / 越到后面越不像

**原因**：用文字描述了长相，或者主体参考素材太少、太短。

**改法**：
1. 上传参考图，提示词里删掉所有外貌描述
2. 主体音视频素材控制在 5–10 秒，太短（2 秒）特征不完整，太长（30 秒）特征被稀释
3. 主体超过 5 个时改用单视图，别用多视角拼图

### 多个角色串味 / 张冠李戴

**原因**：没写素材职责映射，模型自己猜的。

**改法**：每个素材紧跟一句声明，把对应关系写死：

```
@图片1 用于男主角的五官和发型。
@图片2 用于女主角的五官和发型。
@图片3 用于男主角的西装款式，不采用图中人物。
```

### 画面里出现了多个同一个人 / 同一件产品

**原因**：传了同一对象的多个视角，但没说明它们是同一个。

**改法**：加一句总结：

```
以上四张图共同定义同一盏台灯，成片中始终只有一盏台灯。
```

### 肢体扭曲、多手多脚

**原因**：动作描述过于复杂，或者同一动作被重复描述。

**改法**：一个镜头只写一个主要动作；负向词加 `不要人物肢体扭曲，不要重复的脸`。

## 时长与节奏类

### 动作演完了还剩十几秒

**原因**：只写了一个瞬间，没写发展和结尾。

**改法**：按时间轴切段，明确每段发生什么，写清楚最后一帧停在哪。见 [02 提示词公式](./02-prompt-formula.md#30-秒要按时间轴写)。

### 画面在原地重复 / 循环

**原因**：同上，内容撑不满时长。

**改法**：加入明确的状态变化——天色变化、人物移动到新位置、镜头景别改变，给模型一个「往前推进」的方向。

### 莫名其妙加了慢动作

**原因**：模型在情绪高点有加慢动作的默认倾向。

**改法**：负向词写 `不要慢动作，不要变速，不要重定时`。

### 中间黑场 / 跳切

**改法**：明确写 `一镜到底，不剪辑，全程无黑场，无跳切`。

## 素材类

### 参考图的背景被带进画面了

**原因**：只写了「参考 @图片1」，没排除。

**改法**：加排除项：`@图片1 用于人物外观，不采用图片背景`。

### 参考视频里的人物混进来了

**改法**：`@视频1 仅用于运镜方式与剪辑节奏，不采用其中的人物身份、服装和场景`。

### 传了参考视频，动作却没对上

**原因**：提示词里又用文字复述了一遍动作，和视频里的实际动作冲突。

**改法**：删掉文字复述，只写 `保持 @视频1 的动作轨迹与节奏不变`。

### 白模渲染出来结构对了但很空

**原因**：白模只提供运动和空间骨架，主体、材质、场景、风格仍需文字或参考图补充。

**改法**：

```
保持 @视频1 的镜头运动、时长、构图、空间关系和运动轨迹不变，
以 @图片1 作为材质、光照和整体氛围参考，
将白模材质替换为真实材质，补充自然光影、接触阴影、环境光、反射和空间层次。
```

## 编辑类

### 只想改一处，结果别的地方也变了

**原因**：「其余保持不变」写得太笼统。

**改法**：把要锁的东西逐项列出：

```
人物面部、发型、服装、构图、景别、光线方向、镜头运动轨迹和背景
全部保持不变，唯一改动是<具体的改动内容>。
```

### 新增的元素像贴纸一样浮在画面上

**原因**：没写物理关系。

**改法**：补上接触阴影、遮挡关系、环境光反射、受力反馈：

```
新增元素需产生贴地阴影和合理的接触压迫感，
表面对环境光做出可信反射，随镜头移动保持正确的视差和遮挡关系。
```

### 编辑后画幅 / 时长和预期不符

**原因**：这不是 bug。编辑时画幅严格对齐原片、时长基本对齐原片，**不接受自定义**。首尾帧生视频时画幅对齐首帧图。

**改法**：接受它，或者从源头换一个画幅正确的原片。

### 首尾帧生成的视频里人物变形

**原因**：首帧和尾帧画幅不一致，尾帧被拉伸对齐了。

**改法**：上传前把两张图裁成完全相同的比例和分辨率。

### 续写片段和原片色调对不上

**改法**：续写提示词里明确写 `色调、光线方向、颗粒质感和镜头风格与原片保持一致`。另外，**别一次续写太长**，5 秒一段最稳，长了一致性衰减明显。

## 声音类

### 配了一段不想要的背景音乐

**改法**：`无背景音乐，只保留人物对白、环境声和动作音效`。

### 英文台词被念成中文 / 口音不对

**改法**：台词前明确语言和地区变体：

```
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I thought you weren't coming.}
```

### 多角色对话时音色混了

**改法**：每句台词后面都跟音色标注 `（音色参考 @音频N）`。

### 自动加了字幕

**改法**：`不要字幕，不要文字标记，不要水印`。

## 画面内容类

### 不想要的东西反而出现了

**原因**：用了否定句，「不要出现汽车」里的「汽车」把注意力吸引过去了。

**改法**：改成正向描述，把画面写满，让它没地方放：

```
❌ 街道上不要有汽车
✅ 清晨的空街道，只有风吹动的落叶和地面的水渍
```

### 画面有 AI 感、塑料感

**改法**：

```
超真实电影感写实风格，照片级实拍影像质感。
严格遵循真实物理规律：有重量、有摩擦、有惯性、有接触阴影。
不要 CGI 光泽感，不要游戏引擎质感，不要风格化 3D 外观。
```

再补充材质细节：金属的磨损油污、织物的纤维、皮肤的毛孔——具体的材质词比笼统的「真实」有效得多。

### 光看起来是假的

**改法**：写清光位和光的细节词。`眼神光`、`接触阴影`、`光线衰减` 这三个词对真实感的提升最直接。见 [06 运镜与光线词表](./06-camera-and-lighting.md#光的细节词)。

## 通用调试流程

1. **先短后长** — 用同一段提示词跑 5–8 秒验证方向，对了再扩成 30 秒
2. **一次只改一个变量** — 同时改三处，出问题不知道是哪处的锅
3. **从时间戳定位** — 用带时间戳的写法，崩在第几段一目了然
4. **素材做减法** — 效果不稳时先砍掉风格图和场景图，保留核心角色和产品
