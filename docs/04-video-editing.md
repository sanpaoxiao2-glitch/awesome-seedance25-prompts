# 视频编辑与延长

编辑和延长本质上是参考生成（R2V）的延伸：把已有视频用 `@视频1` 喂进去当原片，再用提示词控制改哪里。模型会锁住原片其余部分，只动你指定的地方。

## 编辑的三步写法

```
1. 用 @视频1 指入待编辑的原片
2. 圈定要改的对象和目标
3. 加一句「其余保持不变」锁住未改动区域
```

**第三步不能省**。不写锁定，模型很容易顺手改掉别的东西——你只想换件衣服，它把背景也换了。

最小可用的编辑提示词：

```
将 @视频1 中深色外套男子的服装替换为 @图片1 的款式，
人物动作、面部、镜头运动和背景保持不变。
```

## 编辑会强制锁定的参数

用编辑、延长、首尾帧能力时，模型会**依据参考素材自动锁定部分生成参数，不接受自定义**：

### 视频编辑

- 输出画面比例**严格对齐原片**，不会因为改了内容而变形或裁切
- 输出时长**基本对齐原片**（处理机制导致可能有轻微差异），主体内容与原片保持完整

在提示词里写「输出 16:9」「输出 20 秒」对编辑无效，别浪费篇幅。

### 视频延长

- 输出画面比例**严格对齐原片**，保证延长片段和原片在同一画幅下衔接
- 延长片段的时长**支持自定义**，在提示词里直接写「续写 5 秒」

### 首帧 / 首尾帧生视频

- 输出画幅**对齐首帧图**
- 尾帧画幅与首帧不一致时会被拉伸对齐，**建议输入前先裁成一致**
- 时长支持自定义

## 五类编辑操作

### 1. 指令编辑 — 用文字改画面

支持时间戳，指定编辑生效的时段：

```
将 @视频1 中 0:02–0:05 时段的背景替换为雪山脚下的木屋，
人物动作、服装与镜头节奏保持不变。
```

不写时间戳就是全片生效。

### 2. 参考图编辑 — 用图改画面

```
将 @视频1 中女主手里的马克杯替换为 @图片1 的保温杯，
杯子在画面中的位置、握持角度和光照方向保持一致，其余不变。
```

### 3. 新增主体

在原片里加人、加道具、加特效：

![新增特效：火车冲破银幕](../assets/clips/train-breakout.webp)

上图是一个极端例子：原片是老放映厅的黑白画面，编辑后新增了冲破银幕的蒸汽火车，同时保留了原片的手持运镜、放映厅光线和观众。

```
保持 @视频1 的人物、环境、构图与运镜完全不变，
在人物右手中新增一把发着微光的长弓，弓与手的接触符合真实握持关系，
弓身对环境光有可信的反射，并在地面留下接触阴影。
```

**新增元素时一定要写物理关系**（接触阴影、遮挡、反光），否则加进去的东西会像贴纸一样浮在画面上。

### 4. 删除主体

删水印、删穿帮、删多余人物，模型会对空缺区域自然补全：

```
删除 @视频1 中背景里的所有路人，只保留画面中央的主角，
删除区域用符合场景的街道背景自然补全，其余画面保持不变。
```

简单场景可以写得很短：

```
视频编辑：删除 @视频1 中除主角外的所有人。
```

### 5. 音频编辑

```
保持 @视频1 的画面与运镜完全不变，
将背景音乐替换为 @音频1，保留原片中的人物对白和环境声。
```

## 三类延长

### 向后续写

以原片尾帧为起点往后接：

```
以 @视频1 的尾帧为起点续写 6 秒：
主角走出画面右侧，天色渐暗，路灯次第亮起，最后停在空街道的全景。
画面与音频与原片无缝衔接，色调和镜头风格保持一致。
```

### 向前补前情

以原片首帧为终点往前补：

```
以 @视频1 的首帧为终点，向前补 4 秒前情：
主角从街道远处走入镜头前的过程，画面风格、光线和运镜与首帧保持一致。
```

### 中间补全 · 无缝转场

给两段视频，让模型生成中间的过渡：

```
在 @视频1 与 @视频2 之间生成 3 秒过渡段，
实现画面、色调与运镜的无缝衔接，不出现硬切和黑场。
```

## 连续续写：一段一段接

延长可以套娃。把第一次续写的结果当作新的原片，再续写下一段，这样能把一个 5 秒的镜头滚成一分钟的完整叙事。

| 原片 | 第 1 次续写 |
|---|---|
| ![发芽原片](../assets/clips/sprout-extend-1.webp) | ![续写片段](../assets/clips/sprout-extend-2.webp) |

```
第 1 次：在 @视频1 基础上续写 5 秒 —— 蜜蜂飞来落在花上，微距特写腿部沾满花粉。
第 2 次：在 @视频2（上一步结果）基础上续写 5 秒 —— 延时质感，花瓣凋谢，花蕊膨胀成果实。
第 3 次：在 @视频3 基础上续写 5 秒 —— 果实裂开，种子滑落，镜头跟随落入泥土。
```

每次续写都写清楚「在 @视频N 的基础上」和具体秒数，**别一次要求续写 20 秒**——续得越长，和原片的一致性衰减越明显。5 秒一段是比较稳的粒度。

## 常见问题

**改了一处，别处也变了**
→ 「其余保持不变」这句话写得不够具体。把要锁的东西列出来：`人物面部、服装、构图、光线、镜头运动、背景全部保持不变`。

**新增的元素像贴上去的**
→ 补物理关系：接触阴影、遮挡关系、环境光反射、受力反馈。

**续写片段和原片色调对不上**
→ 在续写提示词里明确写「色调、光线方向、颗粒质感与原片保持一致」。

**编辑后时长变了几帧**
→ 正常现象，模型处理机制导致的轻微差异，主体内容不受影响。
