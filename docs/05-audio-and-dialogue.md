# 声音与多语言

Seedance 2.5 原生生成同步音频。不写声音，模型会自己配——通常是一段和内容无关的背景音乐。**声音这一项建议永远写。**

## 四个特殊符号

提示词可以直接用自然语言描述声音。需要精确区分音乐、音效、台词、字幕时，用这套符号：

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `()` | `(背景播放舒缓节奏的钢琴乐)` |
| 音效 | `<>` | `<远处传来钟声>` |
| 台词 | `{}` | `{你好，欢迎回来}` |
| 字幕 | `【】` | `【第一章：启程】` |

混着用的例子：

```
雨夜的便利店门口，男人站在屋檐下点烟。
(低音提琴的单音持续铺底) <雨点敲打铁皮雨棚的密集声> <打火机滚轮的两次空转>
他终于点着，吸了一口，对着雨幕说：{还是没赶上。}
【第三夜】
```

## 关掉不想要的声音

模型的默认倾向是「加背景音乐」和「加字幕」。不想要就明确写：

```
无背景音乐，只保留人物对白、环境声和动作音效。
不要字幕。
不要任何声音。
```

这三句是最常用的。纪录片质感、真实感优先的片子，第一句几乎必写。

## 台词的语言控制

### 基础：台词前标明语言

台词不是中文时，在台词前明确说：

```
女孩用日语轻声说：{もう大丈夫です}
```

不标语言的话，模型有时会把英文台词念成中文腔，或者干脆换成中文。

### 进阶：控制口音和地区变体

推荐公式：

```
台词语言 + 地区变体或口音 + 表达方式 + 说话人 + {台词内容}
```

例子：

```
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I thought you weren't coming.}
```

```
台词语言：地道的洛杉矶美式英语。年轻男子用自然的洛杉矶口语说：{No way, you actually made it.}
```

```
台词语言：英式英语，牛津腔。老教授用缓慢、带停顿的语调说：{That, I'm afraid, is where you're mistaken.}
```

**「表达方式」这一项别省**。同一句台词，「用自然口语化的语气说」和「用紧张、压低的声音说」，出来的表演完全不同。

## 音色参考

上传音频当音色参考，配合多角色使用：

```
@音频1 用于男主角的音色，中年、低沉、语速偏慢。
@音频2 用于女主角的音色，年轻、清亮。

男主角看着窗外说：{天要下雨了。}（音色参考 @音频1）
女主角在他身后回答：{伞在玄关。}（音色参考 @音频2）
```

多角色对话时，**每句台词后面都跟上音色标注**，否则模型会混淆谁是谁。

## 只用音频当参考

2.5 新增的能力。传一段 BGM 或人声，让画面跟着它走：

```
@音频1 用于整片的节奏基准。
画面剪辑点、人物动作起落和镜头切换全部对齐 @音频1 的鼓点。

内容：城市夜跑。跑者穿过便利店灯光、地下通道、高架桥下和滨江步道，
每次场景切换都落在音乐的重拍上。
手持跟拍，轻微晃动，霓虹反射在湿滑路面上。
```

用途：卡点视频、MV、需要精确对齐节拍的广告。

## 多语种同步发行

一条母版出多语言版本，用视频编辑能力实现：

**先做母版：**

```
@图片1 是产品图，@图片2 是主播和场景图。
主播看着镜头讲解，双手配合台词自然挥动，表情真实自然。
0-3s   台词：{清晨第一杯咖啡，等不了。}
3-8s   按下开关的动作，台词：{按一下，三秒出杯。}
8-14s  台词：{办公室、出差、深夜赶稿，现磨咖啡随身就有。}
14-20s 台词：{打工人续命神器，限时直降。}
```

**再逐语种改写：**

```
将 @视频1 中的人物换成美国女性，旁白与台词改成英语，其余保持不变。
将 @视频1 中的人物换成西班牙男性，旁白与台词改成西班牙语，其余保持不变。
将 @视频1 中的人物换成印尼女性，旁白与台词改成印尼语，其余保持不变。
```

口型会跟着语种走，不需要额外指定。

同一条预告片的两个语种版本，画面、剪辑和口型全部对齐：

| 英语版 | 日语版 |
|---|---|
| ![预告片英语版](../assets/clips/trailer-en.webp) | ![预告片日语版](../assets/clips/trailer-ja.webp) |

**只换语言不换人**的写法更简单：

```
将 @视频1 中声音、台词、旁白和标题字幕里的英语全部改为法语，其余保持一致。
```

## 一条片子里切多种语言

多语言可以在同一条片子里切换，人物形象和情绪保持连贯：

```
一位博物馆讲解员依次穿过四个展厅，面对不同展品切换语言讲解，
形象、语速和情绪全程一致。

0-7s    港口模型厅，英语。讲解员：{This was never just a destination.}
7-15s   陶瓷香料厅，中文。讲解员：{这些瓷器和香料，记录的是一条从海上长出来的生活方式。}
15-22s  贸易长廊，马来语。讲解员：{Perdagangan menghubungkan banyak budaya.}
22-30s  旅行物件厅，日语。讲解员：{旅の品物は、新しい意味を持ちます。}

镜头：纪录片风格，缓慢的展厅行走镜头，讲解员画面与展品特写交替。
声音：无背景音乐，保留展厅环境的轻微回声。
```

## 支持的语言

中文、英语、西班牙语、印尼语、马来语、泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语等 10 余种。

出海内容可以直接用母语写提示词，不需要先翻译成中文或英文。
