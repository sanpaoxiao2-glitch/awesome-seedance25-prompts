# 参考素材怎么配

50 个参考位是 2.5 最大的卖点，也是最容易用砸的地方。**传得多不等于效果好**，配比不对反而会互相干扰。

## 核心原则：能上传的就别用文字描述

这是最重要的一条。有了参考图之后，提示词里就不该再出现「她有一头棕色卷发，穿着深绿色围裙」这类描述——文字描述和参考图打架的时候，出来的往往是四不像。

正确分工：

- **参考素材**负责「长什么样」
- **提示词**负责「做什么」和「这个素材用来干什么」

## 素材职责必须写进提示词

上传素材后，每引用一个就紧跟一句使用声明。**不要指望模型自己判断哪张图对应哪个人**，也不要依赖图片里的文字标注。

模板：

```
@图片1 用于<主体>的<外貌 / 服装 / 结构 / 材质>，不采用<容易误带入的部分>。
@视频1 用于<动作 / 运镜 / 节奏>，不采用<视频里的人物身份 / 服装 / 场景>。
@音频1 用于<角色或声音类型>的<音色 / 台词 / 环境声 / 音乐>。

<主体>在<场景>中完成<主要动作>。
画面呈现<视觉风格>，镜头采用<镜头表达>。
```

反面写法：

```
❌ 参考 @图片1 生成视频
❌ 结合 @图片1 @图片2 @图片3 的风格
```

这种「无头无尾」的引用，模型只能猜，多素材时基本必错。

正面写法：

```
✅ @图片1 用于陶艺师的五官、发型和深绿色围裙，不采用图片背景。
✅ @图片2 用于工作室的木质台面、窗户位置和晨间光线，不采用图中人物。
✅ @视频1 用于双手拉坯到放置成品的动作节奏，不采用视频中的人物身份、服装和场景。
```

## 同一个东西的多个视角

产品类素材经常需要多角度。

![同一产品的多视角参考图](../assets/refs/ref-headphones.webp)

这时候要明确告诉模型「这几张是同一个东西」，否则它可能生成好几个：

```
@图片1 定义同一盏折叠台灯的正面外观。
@图片2 定义同一盏折叠台灯的左侧结构。
@图片3 定义同一盏折叠台灯的右侧结构。
@图片4 定义同一盏折叠台灯的背面结构。
四张图共同定义同一盏折叠台灯，成片中始终只有一盏折叠台灯。
```

最后那句总结不能省。

## 主体几个最稳

「主体」指画面里希望贯穿全片、稳定还原的核心元素——人物角色、关键产品道具、场景环境、整体风格都算。

比如「一个人在森林里拉弓射中一只兔子」，主人公、弓箭、兔子各算一个主体，都需要稳定还原。

典型的主体参考图——人物、服装、道具、场景各算一个：

| 人物 | 服装 | 道具 | 场景 |
|---|---|---|---|
| ![人物参考](../assets/refs/ref-portrait-woman.webp) | ![服装参考](../assets/refs/ref-trench-coat.webp) | ![道具参考](../assets/refs/ref-elephant.webp) | ![场景参考](../assets/refs/ref-empty-room.webp) |

注意这几张的共同点：**主体在画面中干净、居中、无干扰背景**。参考图本身越杂，模型越容易把不该带的东西带进来。

实测下来的稳定区间：

### 主体用音视频素材时

- **建议 ≤ 5 个主体**，需要的话可以试到 6–10 个
- **单段素材控制在 5–10 秒**，这是识别度和稳定性的最佳区间
  - 太短（2 秒左右）信息量不足，特征不完整，识别不稳
  - 太长（接近 30 秒）关键特征被稀释，噪声增多

### 主体用图片时

- **建议 ≤ 8 个主体**，需要的话可以试到 9–12 个
- 主体 ≤ 5 个时，单视图、多视图都行
- 主体 > 5 个时，**用单视图更稳**
- 需要多视角就拆成多张不同角度的图，**不要传一张拼了多个视角的拼图**

## 素材超载时的取舍优先级

```
核心角色  >  关键产品 / 道具  >  场景环境  >  整体风格
```

位置不够就从右往左砍。场景和风格用文字描述的损失，远小于角色和产品用文字描述的损失。

## 配额分配的实战建议

50 个位置怎么分，按片子类型不同：

| 片子类型 | 建议配比 |
|---|---|
| 单人口播 / 人物宣传 | 模特多视图 3–5 张 + 场景图 1–2 张 + 音色参考 1 段 |
| 产品广告 | 产品多视图 4–6 张 + 场景图 2–3 张 + 参考运镜视频 1 段 + BGM 1 段 |
| 多角色群像 | 每个角色单视图 1 张（最多 10 人）+ 场景图 2–3 张 + 每人音色 1 段 |
| 动作迁移 | 动作参考视频 1 段（5–10 秒）+ 目标形象图 1–3 张 |
| 白模渲染 | 白模视频 1 段 + 材质 / 光照参考图 1–2 张 |
| 分镜预演 | 分镜图（宫格或序列）+ 主角形象图 1–2 张 |

留一部分位置空着不是浪费。**素材越多，模型分配注意力的压力越大**，非必要的风格图往往是负收益。

## 首帧 / 尾帧的坑

指定参考图作首帧或尾帧时：

- 输出画幅**对齐首帧图**，提示词里写比例不生效
- 首尾帧画幅不一致时，**尾帧会被拉伸对齐首帧**，人和物都会变形

所以传首尾帧之前，**先把两张图裁成完全相同的比例和分辨率**。这个坑踩过一次就记住了。

## 参考视频已经说清楚的事，别再用文字复述

当参考视频已经准确给出了动作、运镜和顺序，提示词只需要说明继承哪些内容：

```
✅ 保持 @视频1 的运镜轨迹、时长、构图和动作节奏不变
```

不要逐个动作复述一遍。你的文字描述和视频里的实际动作总会有偏差，这个偏差会变成冲突，模型两边都不讨好。

**例外是白模视频**：白模只提供运动和空间骨架，主体、场景、材质、风格仍然需要你写清楚。
