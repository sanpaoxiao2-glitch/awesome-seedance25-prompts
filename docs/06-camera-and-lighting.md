# 运镜与光线词表

模型对影视术语的理解比对形容词的理解可靠得多。写「缓慢推近」比写「镜头很有电影感地靠近」稳定十倍。

## 景别

| 术语 | 英文 | 画面内容 |
|---|---|---|
| 大远景 | extreme wide shot | 环境为主，人物极小或不可见 |
| 远景 / 全景 | wide shot | 人物全身 + 完整环境 |
| 中景 | medium shot | 腰部以上 |
| 近景 | close-up | 肩部以上 |
| 特写 | extreme close-up | 面部局部、手部、物件细节 |
| 过肩镜头 | over-the-shoulder | 从一人肩后拍另一人，对话场景常用 |
| 主观视角 | POV | 以角色眼睛为机位 |

## 镜头运动

### 基础运动

| 术语 | 英文 | 说明 |
|---|---|---|
| 推 | push in / dolly in | 机位向前靠近主体 |
| 拉 | pull back / dolly out | 机位向后远离，常用于收尾 |
| 摇 | pan（左右）/ tilt（上下） | 机位不动，镜头转向 |
| 移 | tracking / truck | 机位平行移动 |
| 升降 | crane up / down | 机位垂直升降 |
| 环绕 | orbit / arc shot | 绕主体旋转，展示立体感 |
| 跟随 | follow shot | 跟着主体移动 |

### 风格化运动

| 术语 | 效果 |
|---|---|
| 手持 handheld | 轻微晃动，纪录片和临场感 |
| 斯坦尼康 steadicam | 移动中保持平稳，长镜头首选 |
| 甩镜 whip pan | 快速横摇，常用作转场 |
| 变焦推拉 dolly zoom | 眩晕效果，主体不变背景变形 |
| FPV 穿越 | 第一人称高速飞行，带姿态倾斜和惯性 |
| 一镜到底 one-shot / oneer | 不剪辑，30 秒直出的主力用法 |

### 组合运镜

2.5 能稳定执行复合运镜。

![环绕运镜](../assets/clips/orbit-shot.webp)

写法是按顺序描述，别堆在一起：

```
✅ 镜头先跟随人物平移，随后缓慢升起，最后环绕至正面停下。
❌ 跟随升降旋转组合运镜。
```

## 焦点与衔接

| 需求 | 写法 |
|---|---|
| 变焦点 | `焦点从前景的手部转移到背景的门口` |
| 浅景深 | `浅景深，背景虚化，只有主体清晰` |
| 从虚到实 | `开场焦距由虚渐实，主体逐渐清晰` |
| 硬切 | `直接切到<下一个画面>` |
| 转场 | `以甩镜 / 前景遮挡 / 运动模糊完成转场` |
| 无缝衔接 | `画面与音频无缝衔接，不出现黑场` |

## 光线

### 光位

| 术语 | 效果 |
|---|---|
| 顺光 | 正面均匀，最平，广告产品图常用 |
| 侧光 | 明暗交界明显，立体感强 |
| 侧逆光 / 轮廓光 | 边缘发光，头发丝呈半透明，人像质感首选 |
| 逆光 | 剪影或大光比 |
| 顶光 | 正午刺眼感，眼窝有阴影 |
| 底光 | 恐怖 / 诡异氛围 |
| 伦勃朗光 | 侧上方 45°，暗部脸颊出现三角光斑 |

### 光质与色温

```
柔光 / 硬光
暖调（钨丝灯、日落、烛光）/ 冷调（阴天、月光、荧光灯）
高调（整体明亮，阴影少）/ 低调（大面积暗部，局部亮）
高对比 / 低对比
```

### 光的细节词

这些词能显著提升真实感，2.5 对它们的响应很好：

```
眼神光          — 人物眼球表面的高光，判断人像质量的快速指标
接触阴影        — 物体与地面接触处的深色阴影，缺了就会"漂浮"
光线衰减        — 光源到暗部的过渡，写了会更自然
体积光 / 丁达尔  — 光束在雾气或尘埃中可见
流动光          — 车窗外扫过的光影，行进镜头常用
环境光遮蔽      — 缝隙和转角处的自然变暗
```

| 眼神光 | 流动光 |
|---|---|
| ![眼神光](../assets/clips/catchlight.webp) | ![流动光](../assets/clips/moving-light.webp) |

用法示例：

```
暖金色低角度侧逆光，人物额前发丝呈半透明漫反射，
面部明暗交界过渡细腻，转头时眼球表面浮起清晰的眼神光，
暗部保留可见细节。
```

## 质感与风格

| 想要的效果 | 写法 |
|---|---|
| 实拍电影感 | `超真实电影感写实风格，照片级实拍影像质感` |
| 纪录片 | `纪录片街拍风格，自然光，无重度调色滤镜` |
| 商业广告 | `商业产品广告片质感，布光均匀柔和，背景干净` |
| 胶片 | `35mm 胶片质感，细腻颗粒，轻微暗角` |
| 老电影 | `黑白老电影质感，颗粒、划痕、轻微闪烁` |
| 动画 | `3D 动画短片风格，色彩明亮通透` |
| 定格动画 | `定格动画质感，黏土材质，移轴镜头` |
| 水墨 | `水墨动画风格，留白，笔触晕染` |
| 岩彩 / 壁画 | `矿物颜料质感，赭石、石青、石绿、朱砂，平面分层` |

## 排除 AI 感的负向词

想要实拍质感时，这几条很管用：

```
不要 CGI 光泽感，不要游戏引擎质感，不要风格化 3D 外观。
严格遵循真实物理：有重量、有摩擦、有惯性、有接触阴影，不漂浮，不卡通化夸张。
不要舞台表演式打光，不要过度调色滤镜。
不要慢动作，不要变速。
```

最后一条尤其重要——**模型在"重要时刻"有加慢动作的倾向**，不想要就明确关掉。
