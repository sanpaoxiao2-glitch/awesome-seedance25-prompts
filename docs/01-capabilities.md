# 能力与硬参数

写提示词之前先知道边界在哪，能省掉一大半无效尝试。

## 输出

| 项目 | 规格 |
|---|---|
| 单段直出时长 | 最长 30 秒，无需后期拼接 |
| 画幅 | 常规比例可指定；**编辑和延长时强制对齐原片**，不可自定义 |
| 语言 | 原生支持 10 余种：中文、英语、西班牙语、印尼语、马来语、泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语等 |

**画幅这条经常被忽略**：做视频编辑时，输出比例严格对齐原片，不会因为你在提示词里写了 16:9 就改。同理，用首帧图生视频时，输出画幅对齐首帧图；如果首尾帧画幅不一致，尾帧会被拉伸对齐，人物会变形。**传首尾帧前先把两张图裁成一样的比例。**

## 参考素材上限

一次生成最多 50 个素材，三类模态分别有配额：

### 图片 · 最多 30 张

- 分辨率 4K 以内
- 单张 ≤ 30MB
- 格式：jpeg、png、webp、bmp、tiff、gif、heic、heif

### 视频 · 最多 10 段

- 支持 480p – 4K
- 单个 ≤ 200MB
- 格式：mp4、mov
- 单段时长 2–30 秒，**所有视频加起来 ≤ 30 秒**

### 音频 · 最多 10 段

- 单个 ≤ 15MB
- 格式：mp3、wav
- 单段时长 2–30 秒，**所有音频加起来 ≤ 30 秒**

> ⚠️ 视频总时长和音频总时长**分开计算**，各有 30 秒额度。也就是说你可以传满 30 秒视频 + 30 秒音频，不会互相挤占。

## 模态组合

支持 7 种组合，2.5 新增了「只给音频」这一种：

| 组合 | 典型用途 |
|---|---|
| 只给图片 | 角色 / 产品外观锁定 |
| 只给视频 | 动作迁移、运镜复用 |
| 只给音频 🆕 | 用 BGM 驱动画面节奏、卡点、口型 |
| 图片 + 视频 | 换主体但保留动作，最常用的组合 |
| 音频 + 视频 | 换 BGM 但保留画面 |
| 图片 + 音频 | 静态素材配指定配乐 |
| 图片 + 视频 + 音频 | 完整制片，可指定其中某张图作首 / 尾帧 |

三模态同时使用时，仍然可以指定其中的参考图担任首帧或尾帧。

## 三类能力，别搞混

这是 2.5 最容易出问题的地方——参考、编辑、延长的提示词写法完全不同，混用会导致模型不知道该保留什么。

### 参考生成（R2V）

**手上没有成片**，用图 / 视频 / 音频当参考，从零生成一段新视频。

```
Prompt = 生成要求（文本）+ 参考素材（@图片N @视频N @音频N）
```

覆盖的子能力：主体参考、运动参考、白模渲染、风格参考、音频参考、分镜故事板参考、关键帧（首帧 / 首尾帧）、多素材一键成片。

### 视频编辑

**手上已有成片**，只改其中局部，其余锁死。

```
Prompt = 修改要求（文本）+ @视频1（原片）+ 可选 @图片N / @音频N
```

覆盖：指令编辑（可带时间戳）、参考图编辑、新增主体、删除主体、音频编辑。

### 视频延长

**手上已有成片**，基于它的画面、节奏、风格续写。

```
Prompt = 续写要求（文本）+ @视频1（原片）+ 可选 @图片N / @音频N
```

覆盖：向后续写、向前补前情、两段视频之间补全实现无缝转场。

延长片段的时长**可以自定义**，在提示词里直接写「续写 5 秒」即可。这是它和编辑的一个关键差别（编辑的输出时长基本锁死在原片时长）。

详细写法见 [04 视频编辑与延长](./04-video-editing.md)。

## 生成质量的实际水平

按官方给出的评估维度和公开样片，2.5 相比 2.0 的提升集中在四块：

**光**：光源方向统一，衰减自然。人物左右眼接收到的光强不同、虹膜明暗有差异这种细节能还原，**眼神光是判断质量的一个快速指标**。

| 眼神光 | 车窗流动光 |
|---|---|
| ![眼神光特写](../assets/clips/catchlight.webp) | ![车窗流动光](../assets/clips/moving-light.webp) |

左：侧逆光下眼球表面的高光与湿润感，左右眼受光强弱不同。右：行进中车窗外的光影扫过侧脸，明暗过渡贴合车厢环境，不跳脱成漂浮光斑。

**镜头运动**：推拉摇移的轨迹更稳，跟随 + 升降 + 旋转的复合运镜在 30 秒长镜头里不容易漂。

**表演**：能读懂「紧张 → 确认 → 泪笑 → 释然」这种几秒内的多层情绪递进，微表情（眼角颤动、嘴唇轻抿）会给。

| 复杂情绪递进 | 低光人像质感 |
|---|---|
| ![多层情绪](../assets/clips/emotion-layers.webp) | ![香水广告](../assets/clips/perfume-ad.webp) |

**真实感**：皮肤质地、毛发光泽、面部微动更接近实拍，AI 感明显减弱。

对写提示词的直接影响：**情绪可以直接用自然语言描述，不用拆成动作**。写「她强忍着不让眼泪掉下来」比写「眼睛睁大，嘴唇抿紧，头微微上仰」效果更好。
